# Credentials, costs and manual production requirements

No secret values belong in chat, committed files, build artifacts or CLI arguments. Environment examples contain names only. Set provider secrets in the target environment and confirm the exact project/workspace before any deploy.

| Credential/configuration                    | Where                                           | Purpose / rotation                                                                                                  |
| ------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Supabase URL + publishable key              | Vercel public build/runtime                     | Browser RLS access; never use secret/service-role keys here                                                         |

| ANALYTICS_URL                               | Vercel server only                              | Render public HTTPS origin, no credentials/path/query                                                               |
| ANALYTICS_SERVICE_TOKEN                     | Vercel + Render, GitHub production smoke secret | Same >=32-character random value; independent from cron; coordinate both sides during rotation                      |

## Cost and quota review (checked 2026-11-01; confirm provider dashboards before purchase)

| Provider               | Cost/quota responsibility                                                                                                                                                                                                                                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vercel                 | Pro subscription plus compute/invocations/transfer overages; minute crons consume function usage. Hobby daily-only crons are insufficient. See [cron pricing](https://vercel.com/docs/cron-jobs/usage-and-pricing) and [pricing](https://vercel.com/pricing).                                                 |
| Render                 | Selected paid 0.5c-512mb service bills while running; higher plans/multiple instances add cost. No disk is needed. Pricing is quoted by the provider at apply time; no purchase was made. See [compute catalog](https://render.com/docs/compute-plans) and [pricing](https://render.com/pricing).             |
| Supabase               | Database compute, backups/PITR, Storage size/egress and Auth user quotas depend on plan. Videos can dominate storage and transfer. Verify backup retention and egress before launch.                                                                                                                          |
| SMTP                   | Sender verification, recipient/daily limits, bounce suppression and billing depend on the selected SMTP provider. Supabase's default sender is restricted to authorized addresses and approximately 2 messages/hour, unsuitable for production. [SMTP docs](https://supabase.com/docs/guides/auth/auth-smtp). |
| COROS                  | Existing code budgets original FIT retrieval at 50/day/account and defers rather than inventing sync success. Verify current official partner/service quotas for real accounts; no account acceptance is claimed.                                                                                             |
| OpenStreetMap/Overpass | ODbL attribution/license requirements; community Overpass is rate/resource constrained. Use one reviewed small pilot extract, not repeated full-city requests. No paid capacity guarantee exists.                                                                                                             |
| OpenFreeMap            | External tile/font/sprite availability is outside app control. Preserve attribution, monitor failures and review provider terms before large-scale use.                                                                                                                                                       |
| Open-Meteo             | Free public APIs are non-commercial; buy the appropriate commercial entitlement or set WEATHER_DISABLED=true. Optional import elevation calls also require a permitted usage basis; weather API keys do not automatically authorize every elevation endpoint.                                                 |
| City of Calgary        | Feed availability, Socrata throttling and open-data terms apply. No guaranteed update SLA; show existing confidence/freshness behavior when feeds are stale.                                                                                                                                                  |

Exact currency totals are intentionally not guessed: region, provider plan, videos, usage and tax are unknown. Review the linked rate cards and set spending alerts before enabling schedules/public signup.

## Release gates and explicit blockers

Create/configure the target Vercel and Render services, choose regions, fund the selected plans, configure TLS/reader login and import the pilot network; enable SMTP and correct Auth callbacks/rate limits; verify native database tzdata and backups; configure deployment checks/protected production environment; run read-only smoke against actual URLs and staging end-to-end flows. Review Form capacity/optional dependency installation and real-footage validation separately. Update legal operator/support/retention details before public launch. None of these manual actions are implied by a passing local build.
